# Changelog

All notable changes to this project will be documented in this file.

The format follows the spirit of *Keep a Changelog*, and the project uses semantic versioning.

## [Unreleased]

### Added

- .NET 8 solution skeleton, initial projects, minimal WPF application, and xUnit test environment;
- unified active documentation;
- consolidated Manifesto;
- Blueprint v1 updated with TMDb as an optional provider;
- target technical architecture;
- SQLite data model;
- development guide;
- Codex working rules for the repository;
- detailed technical backlog;
- focused Roadmap;
- initial ADRs;
- archive directory for founding documents and prototypes.

### Changed

- established English as the sole repository language and harmonized active and archived documentation;
- finalized the documentation structure around `docs/README.md`, with distinct reading paths for humans and Codex;
- harmonized the backlog with module naming, the Roadmap, and explicit user validation;
- integrated a glossary of essential concepts into the Blueprint;
- defined Guardian as a media identity manager and Jellyfin companion;
- moved identification to the work level rather than the individual episode level;
- clarified that TMDb proposes candidates but never validates automatically;
- made historical documentation non-normative.

### Archived

- previous design documents: Vision, Personality, Day Zero, Moments, Project Memory, and Our Method;
- Blueprint predating the documentation consolidation;
- references to the first PowerShell prototypes.
