# Project Memory — Archive

## Identité

Guardian est un projet logiciel personnel développé sur le long terme.

## Objet

Compagnon de Jellyfin, jamais remplacement de Jellyfin.

## Principes fondateurs

- ne jamais toucher au serveur ou à la bibliothèque source de manière destructive ;
- rester non indispensable ;
- être invisible lorsqu’il n’est pas utile ;
- rester léger ;
- préserver la confidentialité ;
- valoriser la collection sans produire un effet de plateforme générique.

## Formules retenues

> La technologie doit disparaître derrière l’expérience.

> Guardian n’ajoute pas des fonctions. Il étend les possibilités offertes par Jellyfin.

> Guardian révèle les liens qui existent déjà.

## Organisation historique

- Guardian 1 : Core ;
- Guardian 2 : Companion ;
- Guardian 3 : Intelligence.

La documentation active conserve uniquement ce qui est nécessaire à la réalisation de la v1.
