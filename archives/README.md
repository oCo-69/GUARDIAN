# Archives

This directory preserves documents and prototypes that contributed to the creation of Guardian.

They are retained as project memory but **are no longer normative documentation**. When documents conflict, the order of authority is:

1. [`docs/01_BLUEPRINT.md`](../docs/01_BLUEPRINT.md)
2. accepted ADRs
3. [`docs/02_ARCHITECTURE.md`](../docs/02_ARCHITECTURE.md) and [`docs/03_DATABASE.md`](../docs/03_DATABASE.md)
4. other active documents
5. archives

Some archived texts were reconstructed and harmonized from design discussions. They preserve the founding ideas without claiming to reproduce every version word for word.
