# Archives

Ce répertoire conserve les documents et prototypes qui ont participé à la naissance de Guardian.

Ils sont conservés pour mémoire, mais **ne constituent plus la documentation normative**. En cas de contradiction, l’ordre de référence est :

1. [`docs/01_BLUEPRINT.md`](../docs/01_BLUEPRINT.md)
2. ADR acceptés
3. [`docs/02_ARCHITECTURE.md`](../docs/02_ARCHITECTURE.md) et [`docs/03_DATABASE.md`](../docs/03_DATABASE.md)
4. autres documents actifs
5. archives

Certains textes d’archives ont été reconstitués et harmonisés à partir des échanges de conception. Ils préservent les idées fondatrices, sans prétendre reproduire chaque version mot pour mot.
