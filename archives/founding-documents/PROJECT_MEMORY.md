# Project Memory — Archive

## Identity

Guardian is a personal software project developed for the long term.

## Purpose

A Jellyfin companion, never a replacement for Jellyfin.

## Founding principles

- never touch the server or Source library destructively;
- remain non-essential;
- remain invisible when not useful;
- stay lightweight;
- preserve privacy;
- enhance the collection without creating the effect of a generic platform.

## Retained statements

> Technology should disappear behind the experience.

> Guardian does not add features. It extends the possibilities offered by Jellyfin.

> Guardian reveals relationships that already exist.

## Historical organization

- Guardian 1: Core;
- Guardian 2: Companion;
- Guardian 3: Intelligence.

Active documentation retains only what is necessary to deliver v1.
