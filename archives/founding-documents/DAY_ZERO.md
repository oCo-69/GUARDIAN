# Day Zero — Archive

Guardian began with a concrete problem: a large Jellyfin library followed a coherent local organization, but some naming conventions and metadata Decisions were misunderstood or weakened by migrations.

The first work focused on:

- Jellyfin database audits;
- locked fields;
- SQLite migrations;
- plugin restoration;
- health reports;
- PowerShell scripts;
- improved web navigation.

Then a deeper question emerged:

> How can Jellyfin understand the collection without modifying it?

The answer first took the form of NFO files, then virtual renaming, and finally a link-based derived library.

Guardian then became more than a maintenance script: it became an interpretation layer and ultimately a memory of media identity.
