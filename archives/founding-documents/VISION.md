# Vision — Archive

Guardian was envisioned as a durable Jellyfin companion organized around three horizons.

## Guardian 1 — Core / Administrator

- audits;
- database health;
- Locks;
- cleanup;
- reports;
- configurable monitoring.

## Guardian 2 — Companion Desktop Web

- keyboard navigation;
- consistent backward navigation;
- focus management;
- Collection indicators on item pages;
- language filters and sorting;
- enhanced search and sorting.

## Guardian 3 — Intelligence / Discovery

- sagas;
- universes;
- eras;
- languages;
- directors;
- internal recommendations;
- nested Collections.

The current v1 narrowed the mission around media identity, Decision memory, and Jellyfin Projection. Horizons 2 and 3 remain possible future directions rather than commitments for the first version.
